# M2.7 – Files between contexts

- Date: 2026-10-17
- Host: Ubuntu 26.04 LTS, Hyprland v0.53.3 nested in GNOME

## Question

Does drag and drop of files work between contexts when the folder is mounted at
the same path in both (exchange folder), and fail otherwise? Which apps pass
paths and which content? Does the clipboard work across contexts?

(The concept's test is "file manager in a context → mail client in `global`".
`global` does not exist yet; context b stands in for it.)

## Setup

Contexts a and b, both with `~/Austausch` mounted at the same path
(`KOJE_SPIKE_MOUNTS`), on the nested Hyprland; Nautilus and foot in a, Firefox
and foot in b. `color-contexts.sh` colors windows by context (a red, b blue) –
without it the windows cannot be told apart (no title bars).

## Result

| Check | Result | Notes |
|---|---|---|
| Nautilus (GTK 4) window on the nested Hyprland | black with the default (Vulkan) and with `GSK_RENDERER=cairo`; **shows with `GSK_RENDERER=gl`** | context without NVIDIA (iGPU via Mesa). Software rendering black too → not a GPU choice issue; recheck in a real session (M2.1) |
| Drag `~/Austausch/shared.txt` from a's Nautilus to b's Firefox | **works** | opens as a tab |
| Drag `~/only-in-a.txt` (not shared) to b's Firefox | **fails, as intended** | the file is only in a's home volume |
| Drag a file onto b's foot: what arrives | the path | `/home/bikeshedder/Austausch/shared.txt` |
| Clipboard text a → b (foot) | **works** | |
| Clipboard image a → b (Firefox) | not tested | |

## Conclusion

Drag and drop between contexts passes **paths**, so it works exactly for files in
folders that both contexts mount at the same path (the exchange folder) and
fails for everything else – the intended "deliberate hole" of the concept. The
clipboard works across contexts (same compositor). Confirms the same-path rule
for `mounts` (ADR 0009) and the home volume at the host path (M2.3).

Still to see in a real session: dragging into a mail client in `global` (the
context does not exist yet, M3.10), and an image on the clipboard.
