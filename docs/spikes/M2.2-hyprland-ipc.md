## Question

Can koje list, move and color windows and follow window events through
Hyprland's sockets from Rust, and is one batched request fast enough for layout
switches? This decides the shape of the `Compositor` port.

## Setup

`docs/spikes/setup/hypr-ipc` (std + serde_json), Hyprland nested in GNOME with
`docs/spikes/setup/hyprland-nested.conf`.
