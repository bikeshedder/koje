# M2.2 – Hyprland IPC from Rust

- Date: 2026-10-17
- Host: Ubuntu 26.04 LTS, kernel 7.0.0-38-generic, Hyprland v0.53.3 (nested in GNOME)

## Question

Can koje list, move and color windows and follow window events through
Hyprland's sockets from Rust, and is one batched request fast enough for layout
switches? This decides the shape of the `Compositor` port.

## Setup

`docs/spikes/setup/hypr-ipc` (std + serde_json), Hyprland nested in GNOME with
`docs/spikes/setup/hyprland-nested.conf`.

## Result

| Check | Result | Notes |
|---|---|---|

## Conclusion

Hyprland's two sockets give koje everything M4 needs except geometry events.

- **Window → context:** `j/clients` gives the host pid; `/proc/<pid>/cgroup`
  names the context's container (`libpod-<id>.scope`). Confirms concept and M4.4.
- **Batching:** `[[BATCH]]cmd;cmd;…` – 10 commands in 0.09–0.14 ms against
  1.2–4 ms as separate requests. A layout switch is one batch; the cost on the
  koje side is negligible.
- **Colors:** one rule per context matching a tag (ADR 0018).
- **Events:** `openwindow>>addr,workspace,class,title`, `closewindow>>addr`,
  `activewindowv2>>addr`, `windowtitlev2>>addr,title`. **Moving or resizing a
  floating window emits no event**, so autosave (M5.7) cannot be event driven
  alone: kojed re-reads `j/clients` on focus changes and debounced (or at a slow
  interval) and diffs geometry.
- **Syntax drift:** window rule and property syntax changed in 0.53. The
  Hyprland adapter keeps all request strings in one place and is tested against
  a live Hyprland (M4.8).

Suggested shape of the `Compositor` port (M4.2): `windows()`, `apply(batch of
place/focus/tag commands)`, `define_context_rule(tag, active, inactive)`, and an
event stream; replaces the per-window `set_border_color`.

ADRs / plan changes / open questions answered:

- [ADR 0018](../decisions/0018-window-colors-by-tag-rule.md): window colors.
- *Layout switch speed*: batching is fast; whether the animation fits is a
  matter of taste, checked in M5.5 (question narrowed).
- M4.2, M4.5, M5.7 notes point here.
