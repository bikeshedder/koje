# M2.3 – Base image and a hand-made context container

- Date: 2026-10-16 – 2026-10-17
- Host: Ubuntu 26.04 LTS, kernel 7.0.0-38-generic, GNOME (Wayland), Podman 5.7.0, PipeWire 1.6.2, NVIDIA driver 595.91.07, GPU NVIDIA RTX 5090 + Ryzen 9 7950X3D iGPU
- Compositor: GNOME (`wayland-0`). The "Hyprland nested" column is filled during M2.2.

## Question

Can a rootless Podman container with the Wayland socket, PipeWire, `/dev/dri` and a
home volume at the host path run a browser and a terminal on the desktop, with sound
and GPU, and do links opened in the container land in the container's browser?

## Setup

Image: `docs/spikes/setup/base/Containerfile` (Fedora 44, throwaway).

Contexts started with `docs/spikes/setup/run-context.sh <name> wayland-0`
(`KOJE_SPIKE_GPU=nvidia` for the NVIDIA runs). The exact command is in the
conclusion.

Changes needed beyond the first version of the script: see "Problems" below.

Problems and how they were solved:

- `--tmpfs …,uid=,gid=` is not supported by Podman → `--mount type=tmpfs,…,U=true`.
- `sleep infinity` as PID 1 ignores SIGTERM (10 s stop) → `--init`.
- VS Code renderer crashes with the default 64 MB `/dev/shm` → `--shm-size 1g`.
- No session D-Bus → Firefox remoting fails → the context runs its own `dbus-daemon`.
- PulseAudio socket under a root-owned mount point dir → libpulse refuses → socket at its own path + `PULSE_SERVER`.

- NVIDIA's proprietary driver needs its userspace inside the context → CDI
  (`nvidia-container-toolkit`) plus NVIDIA's GBM backend, which the generated
  CDI spec lacks.

## Conclusion

A rootless context container runs Wayland programs on the desktop with GPU,
sound, its own session bus and a home volume at the host path; links opened in
the context land in the context's browser. Startup is almost instant.

The `podman run` spec for M3.2 (from `run-context.sh`, context `b`, NVIDIA; uid 1000):

```sh
podman run -d --name koje-spike-b --hostname b --init \
  --label io.koje.spike=true --label io.koje.context=spike-b \
  --userns=keep-id --security-opt label=disable \
  -v koje-spike-b-home:/home/bikeshedder:U -e HOME=/home/bikeshedder -w /home/bikeshedder \
  --mount type=tmpfs,destination=/run/user/1000,tmpfs-mode=0700,U=true \
  -e XDG_RUNTIME_DIR=/run/user/1000 \
  -e DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus \
  -v /run/user/1000/wayland-0:/run/user/1000/wayland-0 -e WAYLAND_DISPLAY=wayland-0 \
  -e MOZ_ENABLE_WAYLAND=1 -e GDK_BACKEND=wayland -e QT_QPA_PLATFORM=wayland \
  --shm-size 1g \
  --device /dev/dri --device /dev/fuse --device /dev/net/tun \
  -v /run/user/1000/pipewire-0:/run/user/1000/pipewire-0 \
  -v /run/user/1000/pulse/native:/run/user/1000/pulse-native \
  -e PULSE_SERVER=unix:/run/user/1000/pulse-native \
  --device nvidia.com/gpu=all \
  -v /usr/lib/x86_64-linux-gnu/libnvidia-allocator.so.595.91.07:/usr/lib64/gbm/nvidia-drm_gbm.so:ro \
  localhost/koje-spike/base:latest \
  dbus-daemon --session --nofork --nopidfile --address=unix:path=/run/user/1000/bus
```

Plus, from M2.5 (ADR 0014): `--security-opt unmask=/proc/sys`.
