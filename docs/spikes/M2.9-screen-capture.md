## Question

Can programs in a context be denied direct screen capture (`screencopy`) while
screen sharing through the portal (video calls) keeps working?

Two mechanisms: Hyprland's **permission rules** (match the client's executable
path) and **`security-context-v1`** (koje hands each context a Wayland socket
that marks all its clients as sandboxed).

## Setup

Context a from `run-context.sh`; `grim` in the image; `wl-secure-socket` for the
security context socket.
